H: wide and tall figures

NoteAbout this page

This page tests how the viewer opens figures of different shapes: very wide collages (25 × 2 inches), tall strips, a poster, a portrait photo and a small plot, alone, in galleries and in layouts, and the fit option. All are png; other formats are on E: image formats.

By default (fit: auto) very wide figures open at screen height from the left end (or where they were clicked), very tall ones at screen width from the top, and everything else whole, never enlarged past its real size.

Headings carry what the browser test checks: expect-fit (contain, height or width), shift-scroll (which way Shift+scroll moves the image: x sideways, y up and down, none, or zoomed-x: sideways after zooming in until the image extends past the screen both ways) and expect-scale="1" (opens at real size), expect-zoom-out (yes: the opening view is closer than the whole image, so it zooms out; no: it already is the whole image). The first single collage and image shown whole also get the focal point and containment checks.

1. Wide collage, png (25 × 2 in)

```{r}
#| panzoom: true
#| fig-width: 25
#| fig-height: 2
#| fig-cap: "A 25 × 2 inch collage of 12 panels (png)."

collage()
```

2. Wide collage with fit: contain

The override for case 1: the whole collage, as a strip.

```{r}
#| panzoom:
#|   fit: contain
#| fig-width: 25
#| fig-height: 2
#| fig-cap: "The collage, forced to open whole."

collage()
```

3. Moderately wide figure (16 × 4 in)

Wide, but readable whole: the size rule leaves it alone.

```{r}
#| panzoom: true
#| fig-width: 16
#| fig-height: 4
#| fig-cap: "A 4:1 figure."

collage(4)
```

4. Tall strip (4 × 15 in)

```{r}
#| panzoom: true
#| fig-width: 4
#| fig-height: 15
#| fig-cap: "A tall strip of 8 panels."

set.seed(2)
par(mfrow = c(8, 1), mar = c(2, 3, 2, 1))
for (i in 1:8) plot(cumsum(rnorm(100)), type = "l", main = paste("Row", i), xlab = "", ylab = "")
```

5. Large poster (24 × 18 in)

Opens whole; zoomed in, it extends past the screen both ways, and Shift+scroll moves sideways.

```{r}
#| panzoom: true
#| fig-width: 24
#| fig-height: 18
#| fig-cap: "A 24 × 18 inch poster of 48 panels."

set.seed(3)
par(mfrow = c(6, 8), mar = c(2, 2, 2, 1))
for (i in 1:48) plot(cumsum(rnorm(100)), type = "l", main = paste("Panel", i), xlab = "", ylab = "")
```

6. Portrait photo

An ordinary 9:16 photo is not a strip: it opens whole, on any screen width (the test also checks this in a 2560 px wide window).

7. Small plot (288 × 192 px)

Opens at its real size, centered, rather than enlarged to fill the screen; scroll still zooms in (up to max-zoom).

```{r}
#| panzoom: true
#| fig-width: 3
#| fig-height: 2
#| fig-dpi: 48
#| fig-cap: "A small plot."

plot(pressure)
```

8. fit: height on an ordinary plot

On a screen wider than the plot (1.4:1), filling the height is already the whole plot, so this opens like fit: contain and can’t zoom out. Case 15 shows fit: height on a figure where it differs.

```{r}
#| panzoom:
#|   fit: height

wave(3)
```

9. fit: width on an ordinary plot

Filling the width makes the plot taller than the screen: it opens closer than the whole plot, and zooms out to it.

```{r}
#| panzoom:
#|   fit: width

wave(4)
```

10. Gallery of two collages

Left/Right and drags pan along the collage; the ‹ › buttons switch collages.

```{r}
#| panzoom:
#|   group: collages
#| fig-width: 25
#| fig-height: 2
#| fig-cap:
#|   - "First collage."
#|   - "Second collage."

collage()
collage(15)
```

11. Gallery of two tall strips

Each strip opens at screen width and extends downwards: Left/Right do nothing (there is nowhere to go sideways) rather than switch strips; the ‹ › buttons switch.

```{r}
#| panzoom:
#|   group: strips
#| fig-width: 4
#| fig-height: 15
#| fig-cap:
#|   - "First strip."
#|   - "Second strip."

  par(mfrow = c(8, 1), mar = c(2, 3, 2, 1))
  for (i in 1:8) plot(cumsum(rnorm(100)), type = "l", main = paste("Strip", k, "row", i), xlab = "", ylab = "")
}
```

Not a strip (shown whole it is over a quarter of the screen tall), so fit: auto would open it whole. fit: height opens it filling the screen height (but not past its real size), from where it was clicked, and zooms out to the whole figure.

16. Case 15 with a long caption and description

The caption and description sit below the image; fit: height fills the height left above them, so it opens smaller than case 15. The caption scrolls past a quarter of the screen, the description past a fifth, so the image keeps at least about half.

```{r}

#| fig-cap: "Six random walks side by side, opened with `fit: height` under a long description."
```

## About this page

This page **tests how the viewer opens figures of different shapes**:
very wide collages (25 × 2 inches), tall strips, a poster, a portrait
photo and a small plot, alone, in galleries and in layouts, and the `fit`
option. All are png; other formats are on [E: image formats](e-formats.html).

By default (`fit: auto`) very wide figures open at screen height from the
left end (or where they were clicked), very tall ones at screen width from
the top, and everything else whole, never enlarged past its real size.

Headings carry what the browser test checks: `expect-fit` (`contain`,
`height` or `width`), `shift-scroll` (which way Shift+scroll moves the
image: `x` sideways, `y` up and down, `none`, or `zoomed-x`: sideways
after zooming in until the image extends past the screen both ways) and
`expect-scale="1"` (opens at real size), `expect-zoom-out` (`yes`: the
opening view is closer than the whole image, so it zooms out; `no`: it
already is the whole image). The first single collage and
image shown whole also get the focal point and containment checks.
:::

```{r}
#| include: false

# A collage: `n` panels side by side, like a wide patchwork figure.
collage <- function(n = 12) {
  set.seed(1)
  par(mfrow = c(1, n), mar = c(3, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(cumsum(rnorm(200)), type = "l", main = paste("Panel", i),
         xlab = "", ylab = "", col = hcl.colors(n)[i], lwd = 2)
  }
}

# A tall strip: `n` rows stacked, like a tall patchwork figure.
strip <- function(seed = 2, n = 8) {
  set.seed(seed)
  par(mfrow = c(n, 1), mar = c(2, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(cumsum(rnorm(100)), type = "l", main = paste("Row", i), xlab = "", ylab = "")
  }
}

wave <- function(k = 1) {
  x <- seq(0, 4 * pi, length.out = 400)
  plot(x, sin(k * x), type = "l", lwd = 2, col = hcl.colors(4)[k],
       main = paste("Wave", k), xlab = "x", ylab = "sin(kx)")
}
```
