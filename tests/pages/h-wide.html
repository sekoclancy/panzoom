H: wide and tall figures

NoteAbout this page

This page tests how the viewer opens figures of different shapes: very wide collages (25 × 2 inches), tall strips, a poster, a portrait photo and a small plot, alone, in galleries and in layouts, and the fit option. All are png; other formats are on E: image formats.

By default (fit: auto) very wide figures open at screen height from the left end (or where they were clicked), very tall ones at screen width from the top, and everything else whole, never enlarged past its real size.

Headings carry what the browser test checks: expect-fit (contain, height or width), shift-scroll (which way Shift+scroll moves the image: x sideways, y up and down, none, or zoomed-x: sideways after zooming in until the image extends past the screen both ways) and expect-scale="1" (opens at real size). The first single collage and image shown whole also get the focal point and containment checks.

1. Wide collage, png (25 × 2 in)

```{r}
#| panzoom: true
#| fig-width: 25
#| fig-height: 2
#| fig-cap: "A 25 × 2 inch collage of 12 panels (png)."

collage()
```

2. Wide collage with fit: contain

The override for case 1: the whole collage, as a strip.

```{r}
#| panzoom:
#|   fit: contain
#| fig-width: 25
#| fig-height: 2
#| fig-cap: "The collage, forced to open whole."

collage()
```

3. Moderately wide figure (16 × 4 in)

Wide, but readable whole: the size rule leaves it alone.

```{r}
#| panzoom: true
#| fig-width: 16
#| fig-height: 4
#| fig-cap: "A 4:1 figure."

```

## About this page

This page **tests how the viewer opens figures of different shapes**:
very wide collages (25 × 2 inches), tall strips, a poster, a portrait
photo and a small plot, alone, in galleries and in layouts, and the `fit`
option. All are png; other formats are on [E: image formats](e-formats.html).

By default (`fit: auto`) very wide figures open at screen height from the
left end (or where they were clicked), very tall ones at screen width from
the top, and everything else whole, never enlarged past its real size.

Headings carry what the browser test checks: `expect-fit` (`contain`,
`height` or `width`), `shift-scroll` (which way Shift+scroll moves the
image: `x` sideways, `y` up and down, `none`, or `zoomed-x`: sideways
after zooming in until the image extends past the screen both ways) and
`expect-scale="1"` (opens at real size). The first single collage and
image shown whole also get the focal point and containment checks.
:::

```{r}
#| include: false

# A collage: `n` panels side by side, like a wide patchwork figure.
collage <- function(n = 12) {
  set.seed(1)
  par(mfrow = c(1, n), mar = c(3, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(cumsum(rnorm(200)), type = "l", main = paste("Panel", i),
         xlab = "", ylab = "", col = hcl.colors(n)[i], lwd = 2)
  }
}

# A tall strip: `n` rows stacked, like a tall patchwork figure.
strip <- function(seed = 2, n = 8) {
  set.seed(seed)
  par(mfrow = c(n, 1), mar = c(2, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(cumsum(rnorm(100)), type = "l", main = paste("Row", i), xlab = "", ylab = "")
  }
}

wave <- function(k = 1) {
  x <- seq(0, 4 * pi, length.out = 400)
  plot(x, sin(k * x), type = "l", lwd = 2, col = hcl.colors(4)[k],
       main = paste("Wave", k), xlab = "x", ylab = "sin(kx)")
}
```
