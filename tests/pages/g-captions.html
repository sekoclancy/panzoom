G: captions and descriptions

NoteAbout this page

This page tests citations and cross-references in the viewer. A caption is copied from the page, so whatever Quarto renders there comes through. A description is rendered with the page too, in a hidden block the viewer copies, so its citations resolve, its cross-references get numbers, and a work cited only in a description is still listed under References. Quarto’s own lightbox shows a citation in a caption as raw [@key] (quarto-cli#10709).

Cases 1–5 have the expect-references attribute: the viewer must show at least one citation or cross-reference, none unresolved, and each must link to something on this page. Cases 6 and 7 test the per-cell caption and description options (expect-caption).

7. description cell option

The description is Markdown, with math, shown under the caption.

```{r}

#|   description: "A sine wave, $y = \\sin(kx)$, **k = 2**."
#| fig-cap: "With a description."

wave(2)
```

A sine wave, \(y = \sin(kx)\), k = 2.

## About this page

This page **tests citations and cross-references in the viewer**. A
caption is copied from the page, so whatever Quarto renders there comes
through. A description is rendered with the page too, in a hidden block
the viewer copies, so its citations resolve, its cross-references get
numbers, and a work cited only in a description is still listed under
References. Quarto's own lightbox shows a citation in a caption as raw
`[@key]` ([quarto-cli#10709](https://github.com/quarto-dev/quarto-cli/issues/10709)).

Cases 1–5 have the `expect-references` attribute: the viewer must show
at least one citation or cross-reference, none unresolved, and each must

and `description` options (`expect-caption`).
:::

```{r}
#| include: false

wave <- function(k = 1) {
  x <- seq(0, 4 * pi, length.out = 400)
  plot(x, sin(k * x), type = "l", lwd = 2, col = hcl.colors(4)[k],
       main = paste("Wave", k), xlab = "x", ylab = "sin(kx)")
}
```
