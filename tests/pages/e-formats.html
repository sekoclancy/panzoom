E: image formats and very wide figures

NoteAbout this page

This page tests the panzoom extension with the knitr graphics devices and figure shapes used in practice: very wide collages (25 × 2 inches), and webp, svg and pdf output. Every figure is marked with #| panzoom: true and should open the pan/zoom viewer, except where a case says otherwise.

Cases with an expected opening view say so in their heading’s expect-fit attribute (contain, height or width), which the browser test checks. By default (fit: auto) very wide figures open at screen height from the left end, very tall ones at screen width from the top, and everything else whole.

Cases with a shift-scroll attribute say which way Shift+scroll should move the image: x (sideways), y (up and down) or none (it fits, so it stays put); zoomed-x means sideways after zooming in until the image extends past the screen both ways.

Cases with expect-scale="1" are smaller than the screen and must open at their real size (1 image pixel per screen pixel), not enlarged, and still zoom in.

webp comes from ragg’s agg_webp device: knitr has no built-in webp device, and agg_webp needs units = "in" because knitr passes sizes in inches.

1. Wide collage, png (25 × 2 in)

```{r}
#| panzoom: true
#| fig-width: 25
#| fig-height: 2
#| fig-cap: "A 25 × 2 inch collage of 12 panels (png)."

collage()
```

## About this page

This page **tests the panzoom extension** with the knitr graphics devices
and figure shapes used in practice: very wide collages (25 × 2 inches),
and webp, svg and pdf output. Every figure is marked with `#| panzoom: true`
and should open the pan/zoom viewer, except where a case says otherwise.

Cases with an expected opening view say so in their heading's
`expect-fit` attribute (`contain`, `height` or `width`), which the browser
test checks. By default (`fit: auto`) very wide figures open at screen
height from the left end, very tall ones at screen width from the top, and
everything else whole.

Cases with a `shift-scroll` attribute say which way Shift+scroll should
move the image: `x` (sideways), `y` (up and down) or `none` (it fits, so
it stays put); `zoomed-x` means sideways after zooming in until the image
extends past the screen both ways.

Cases with `expect-scale="1"` are smaller than the screen and must open
at their real size (1 image pixel per screen pixel), not enlarged, and
still zoom in.

webp comes from ragg's `agg_webp` device: knitr has no built-in webp
device, and `agg_webp` needs `units = "in"` because knitr passes sizes in
inches.
:::

```{r}
#| include: false

library(ragg)

# A collage: `n` panels side by side, like a wide patchwork figure.
collage <- function(n = 12) {
  set.seed(1)
  par(mfrow = c(1, n), mar = c(3, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(cumsum(rnorm(200)), type = "l", main = paste("Panel", i),
         xlab = "", ylab = "", col = hcl.colors(n)[i], lwd = 2)
  }
}

# A tall strip: `n` rows stacked, like a tall patchwork figure.
strip <- function(seed = 2, n = 8) {
  set.seed(seed)
  par(mfrow = c(n, 1), mar = c(2, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(cumsum(rnorm(100)), type = "l", main = paste("Row", i), xlab = "", ylab = "")
  }
}
```
