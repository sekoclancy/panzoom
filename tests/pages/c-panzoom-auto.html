C: panzoom match: auto

NoteAbout this page

This page tests panzoom’s match: auto mode. The markup is identical to a-lightbox (no panzoom markers at all); both panzoom: match: auto and lightbox: match: auto are on. panzoom should take every image that Quarto’s auto lightbox would take, except where a case asks for something explicit:

  • cases 6 and 7 set #| lightbox: options, so they stay with GLightbox;
  • case 8 sets #| lightbox: false, so it gets neither;
  • case 9 (image inside a link) and case 11 (inline image) are skipped, as Quarto’s auto mode skips them.

Compare each case with the same numbered case in a-lightbox.

6. R chunks with lightbox cell options (group + description)

This chunk sets a lightbox group and description.

```{r}
#| fig-cap: Simple demo R plot
#| lightbox:
#|   group: r-graph
#|   description: This is 1 to 10 plot

plot(1:10, rnorm(10))
```

So does this one, in the same group.

```{r}
#| fig-cap: Plot about cars data
#| lightbox:
#|   group: r-graph
#|   description: We see our cars data above

plot(cars)
```

title: "C: panzoom match: auto"
format:
  html:
    code-tools: true
filters:
  - panzoom
panzoom:
  match: auto
  hint: false
lightbox:
  match: auto
  effect: fade
  desc-position: right
  loop: true
  css-class: my-lb

- case 8 sets `#| lightbox: false`, so it gets neither;
- case 9 (image inside a link) and case 11 (inline image) are skipped, as
  Quarto's auto mode skips them.

Compare each case with the same numbered case in [`a-lightbox`](a-lightbox.html).
