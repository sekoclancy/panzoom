Renderings (Python)

Python cells with renderings: [light, dark], which draw one plot for each color mode, as Renderings (R) does for R cells. The page shows the one for its mode (the toggle in the navbar), and so does the viewer. Each one is worth opening in light and dark mode.

Each case shows its source above the plot: Jupyter leaves panzoom: out of the echoed code of a cell.

The plots are drawn with this helper. ink colors the axes, labels, and title; paper fills the plot background, and "none" leaves it transparent.

```{python}
import matplotlib.pyplot as plt
import numpy as np


def wave(k=1, ink="black", paper="white", col="#3B7DB8"):
    x = np.linspace(0, 4 * np.pi, 400)
    fig, ax = plt.subplots(figsize=(7, 5))
    fig.patch.set_facecolor(paper)
    ax.set_facecolor(paper)
    ax.fill_between(x, np.sin(k * x), color=col, alpha=0.35, linewidth=0)
    ax.plot(x, np.sin(k * x), color=col, linewidth=2)
    ax.set(title=f"Wave {k}", xlabel="x", ylabel="sin(kx)")
    ax.title.set_color(ink)
    ax.xaxis.label.set_color(ink)
    ax.yaxis.label.set_color(ink)
    ax.tick_params(colors=ink)
    for spine in ax.spines.values():
        spine.set_color(ink)
    plt.show()
```

A cell with two plots: black ink on white for light mode, and light gray ink on near-black for dark mode. It opens in panzoom with the plot for the current color mode.

```{python}

#| fig-alt: "A sine curve in blue on a background matching the page"
#| fig-cap: >-
#|   Wave 3: y = sin(3x); the area between the curve and y = 0 is shaded.

wave(3)
wave(3, ink="#D9D9D9", paper="#1E1E1E", col="#7FB8E6")
```
