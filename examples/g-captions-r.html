Captions and descriptions (R)

A caption is copied from the page, so whatever Quarto renders there comes through to the viewer. A description is rendered with the page too, in a hidden block the viewer copies, so its citations resolve, its cross-references get numbers, and a work cited only in a description is still listed under References. In a caption, lightbox shows a citation as raw [@key].

The plots are drawn with this helper:

```{r}
wave <- function(k = 1) {
  x <- seq(0, 4 * pi, length.out = 400)
  col <- hcl.colors(4, "Dark 3")[k]
  plot(
    x,
    sin(k * x),
    type = "n",
    main = paste("Wave", k),
    xlab = "x",
    ylab = "sin(kx)"
  )
  polygon(
    c(x, rev(x)),
    c(sin(k * x), rep(0, length(x))),
    col = adjustcolor(col, 0.35),
    border = NA
  )
  lines(x, sin(k * x), lwd = 2, col = col)
}
```
