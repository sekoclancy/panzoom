Image formats (R)

Two figures, a wide collage and a standard plot, written by different knitr graphics devices: webp, svg, png, pdf, and an animated gif. Every figure has the #| panzoom: true cell option and opens in panzoom unless its case says otherwise. How figures of other shapes open is on wide and tall figures.

knitr has no built-in webp device, so the webp cases use agg_webp from ragg. knitr passes it sizes in inches and no resolution, while ragg expects pixels and draws at 72 dpi, so each webp case sets both under dev.args:

#| dev.args:
#|   units: "in"
#|   res: 96

res: 96 gives the webp the same size as the other figures on the page.

The collage cases draw with this helper:

```{r}
library(ragg)

# A collage: `n` panels side by side, like a wide patchwork figure.
collage <- function(n = 12) {
  set.seed(1)
  par(mfrow = c(1, n), mar = c(3, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(
      cumsum(rnorm(200)),
      type = "l",
      main = paste("Panel", i),
      xlab = "",
      ylab = "",
      col = hcl.colors(n)[i],
      lwd = 2
    )
  }
}
```

1 webp collage

A 25 × 2 inch collage written as webp. It opens in panzoom at screen height.

```{r}
#| panzoom: true
#| fig-width: 25
#| fig-height: 2
#| dev: agg_webp
#| dev.args:
#|   units: "in"
#|   res: 96
#| fig-ext: webp
#| fig-alt: >-
#|   A row of 12 small line plots of random walks, each in its own color
#| fig-cap: "A 25 × 2 inch collage of 12 random walks."

collage(n = 12)
```

6 png and cairo_pdf

The png and pdf plot with the cairo PDF device, which embeds fonts and handles Unicode (µ, Greek letters) and transparency better than pdf. The page shows the png, which opens in panzoom. With a PDF device alone, there is no image to open. Quarto embeds the PDF in a small box with the PDF viewer built into the browser, which panzoom leaves alone.

```{r}
#| panzoom: true
#| dev: [png, cairo_pdf]
#| fig-alt: >-
#|   Filled contour map of Maunga Whau's heights in terrain colors, with a color
#|   key, titled μ = 5, α = 0.05
#| fig-cap: >-
#|   Maunga Whau's heights as filled contours, titled μ = 5, α = 0.05.

filled.contour(
  volcano,
  color.palette = terrain.colors,
  plot.title = title(main = "\u03bc = 5, \u03b1 = 0.05")
)
```

7 webp past its size limit

A 100 × 5 inch collage as webp at 192 dpi. At 19,200 px wide it is past the webp limit of 16,383 px per side, so ragg can’t write the file. The page shows a broken image, and clicking it opens the viewer with “The image could not be loaded.” in place of the image.

```{r}
#| panzoom: true
#| error: true
#| fig-width: 100
#| fig-height: 5
#| dev: agg_webp
#| dev.args:
#|   units: "in"
#|   res: 192
#| fig-ext: webp
#| fig-alt: >-
#|   A row of 12 small line plots of random walks, each in its own color
#| fig-cap: "A 100 × 5 inch collage of 12 random walks."

collage(n = 12)
```

8 Animation

One cell with fig-show: animate and twelve plots, which knitr joins into one animated gif with the gifski package (animation.hook: gifski). It opens in panzoom and keeps playing while it zooms and pans.

```{r}
#| panzoom: true
#| fig-show: animate
#| animation.hook: gifski
#| interval: 0.2
#| fig-alt: "A sine curve sliding to the right over one period, frame by frame"
#| fig-cap: "A sine wave, y = sin(x - t), as t runs over one period."

x <- seq(0, 4 * pi, length.out = 400)
for (t in seq(0, 2 * pi, length.out = 13)[-13]) {
  plot(x, sin(x - t), type = "l", lwd = 2, col = "#3B7DB8", ylab = "sin(x - t)")
}
```
