Divs (R)

Figures inside the divs built into Quarto: callouts, tabsets, page columns, and conditional content, each on its own and inside a .panzoom div. lightbox is off, so clicking an image panzoom leaves alone does nothing.

An image on a tab not selected, or in a collapsed callout, opens once the reader selects the tab or expands the callout.

The plots are drawn with these helpers:

```{r}
# A collage: `n` panels side by side, like a wide patchwork figure.
collage <- function(n = 12) {
  set.seed(1)
  par(mfrow = c(1, n), mar = c(3, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(
      cumsum(rnorm(200)),
      type = "l",
      main = paste("Panel", i),
      xlab = "",
      ylab = "",
      col = hcl.colors(n)[i],
      lwd = 2
    )
  }
}

wave <- function(k = 1) {
  x <- seq(0, 4 * pi, length.out = 400)
  col <- hcl.colors(4, "Dark 3")[k]
  plot(
    x,
    sin(k * x),
    type = "n",
    main = paste("Wave", k),
    xlab = "x",
    ylab = "sin(kx)"
  )
  polygon(
    c(x, rev(x)),
    c(sin(k * x), rep(0, length(x))),
    col = adjustcolor(col, 0.35),
    border = NA
  )
  lines(x, sin(k * x), lwd = 2, col = col)
}
```

```
