Styling with CSS (R)

The viewer styled with CSS. css-class, in the YAML header, adds a class to the viewer, and the rules below use it to set the viewer colors (plum, with pink links), draw a line along the top of the caption band, and make the caption larger and italic.

---
panzoom:
  css-class: plum-viewer
---

The rules apply only to a viewer with that class, so other pages keep the default viewer even if they load the same rules. One image or one code cell can add a class of its own, which applies while that image is open.

The rules are in a raw HTML block on this page. The same block works in any Quarto document:

```{=html}
<style>
.plum-viewer {
  --panzoom-backdrop: rgba(60, 20, 70, 0.9);
  --panzoom-panel-bg: #2d1236;
  --panzoom-panel-fg: #f3e8f7;
  --panzoom-link: #ffb3d9;
}
.plum-viewer .panzoom-panel {
  border-top: 4px solid #d58cf0;
}
.plum-viewer .panzoom-caption {
  font-size: 1.15rem;
  font-style: italic;
}
.sea-viewer {
  --panzoom-backdrop: rgba(10, 50, 60, 0.9);
  --panzoom-panel-bg: #0f3640;
  --panzoom-panel-fg: #e0f4f7;
  --panzoom-link: #7fe0d0;
}
.sea-viewer .panzoom-panel {
  border-top-color: #4fc3c9;
}
.sea-viewer .panzoom-caption {
  font-style: normal;
}
</style>
```

The same rules can also go in a stylesheet file, or straight into the HTML header, each set in the YAML header:

---
format:
  html:
    css: viewer.css   # a file holding the rules above
---
---
format:
  html:
    include-in-header:
      text: |
        <style>
        .plum-viewer { --panzoom-backdrop: rgba(60, 20, 70, 0.9); }
        </style>
---

The .scss file of a theme works too. Rules on parts of the viewer start with its class, as above, so they win over the defaults. The parts are .panzoom-panel (the band or side panel around the caption, description, and hint), .panzoom-caption, .panzoom-description, .panzoom-hint, .panzoom-close, .panzoom-prev, .panzoom-next, and .panzoom-counter.

For a whole site, put css-class (or any option) under format: html: in _quarto.yml. A top-level panzoom: there is replaced, not merged, by the panzoom: options on a page.

2 Class for one image

A markdown image with .panzoom and a class of its own, css-class="sea-viewer". It opens with the dark teal .sea-viewer rules, a teal line along the top of the caption band, and an upright caption, and the link in its caption is teal. The plum-viewer class set under the panzoom: option in the YAML header stays on the viewer too, so the .sea-viewer rules come after the .plum-viewer ones to win over them.

![A gingerbread cottage in Oak Bluffs, Martha's Vineyard ([photo](https://unsplash.com/photos/HQEtvlNzUyA)).](../images/mv-3.jpg){.panzoom css-class="sea-viewer" fig-alt="A shingled gingerbread cottage with pink and green trim, behind a garden path"}

3 Code cell

An R cell with #| panzoom: true. It opens with the plum viewer set under the panzoom: option in the YAML header.

```{r}
#| panzoom: true
#| fig-alt: "Scatter plot of vapor pressure rising steeply with temperature"
#| fig-cap: "Vapor pressure of mercury against temperature."

plot(pressure, type = "b", pch = 19)
```

4 Class for one cell

An R cell with css-class: sea-viewer under the panzoom cell option. It opens with the teal viewer.

```{r}
#| panzoom:
#|   css-class: sea-viewer
#| fig-alt: "Scatter plot of stopping distance against speed for 50 cars"
#| fig-cap: "Stopping distance against speed for 50 cars."

plot(cars, pch = 19)
```

7 Class from a file

A markdown image with .panzoom and css-class="amber-viewer". The rules for that class are in a file, assets/amber-viewer.html in the panzoom repository, which the YAML header includes. It opens with an amber viewer, an amber line along the top of the caption band, and an upright caption, and the link in its caption is gold.

---
format:
  html:
    include-in-header: ../assets/amber-viewer.html
---

The file holds a <style> block. Included in the header, its rules come before the ones on the page, so each starts with .panzoom-overlay too, to win over the .plum-viewer rules above:

.panzoom-overlay.amber-viewer {
  --panzoom-backdrop: rgba(40, 25, 5, 0.92);
  --panzoom-panel-bg: #3a2508;
  --panzoom-panel-fg: #fdf0d8;
  --panzoom-link: #ffc966;
}
![A sailboat off Edgartown, Martha's Vineyard ([photo](https://unsplash.com/photos/IiLiz7XpQpI)).](../images/mv-4.jpg){.panzoom css-class="amber-viewer" fig-alt="A sailboat with a flag-striped sail off a sandy beach"}
