Selecting images (R)

Only images marked with the .panzoom class or the #| panzoom: true cell option open in panzoom. lightbox is not set in the YAML header, so clicking any other image does nothing, except in cells that ask for lightbox with options of their own. The same cases open in lightbox alone on the lightbox comparison, and with lightbox on for the whole page on selected images with lightbox. The YAML header turns on panzoom and turns off the hint line:

---
filters:
  - panzoom
panzoom:
  hint: false
---

8 R subfigures

One R cell with #| panzoom: true and two plots, made subfigures by fig-subcap. Either one opens in panzoom, in a two-image gallery.

```{r}
#| panzoom: true
#| label: fig-r-sub
#| layout-ncol: 2
#| fig-alt:
#|   - "Scatter plot of vapor pressure rising steeply with temperature"
#|   - "Scatter plot of stopping distance against speed for 50 cars"
#| fig-cap: >-
#|   Vapor pressure of mercury, and stopping distances of cars.
#| fig-subcap: ["Pressure", "Cars"]

plot(pressure)
plot(cars)
```

9 Grouped cells

Two R cells in the lightbox group r-graph. The first also has #| panzoom: true, so it opens in panzoom on its own, without the lightbox description. The second has only lightbox options, which turn lightbox on for that cell, so it opens in lightbox as the only image in its group.

```{r}
#| panzoom: true
#| lightbox:
#|   group: r-graph
#|   description: Ten random points.
#| fig-alt: "Scatter plot of ten random points"
#| fig-cap: >-
#|   Ten random points against their index.

plot(1:10, rnorm(10))
```
```{r}
#| lightbox:
#|   group: r-graph
#|   description: Stopping distance against speed.
#| fig-alt: "Scatter plot of stopping distance against speed for 50 cars"
#| fig-cap: >-
#|   Stopping distance against speed for 50 cars.

plot(cars)
```

10 Two plots in one cell

One R cell with #| panzoom: true, two plots, and the lightbox options group: cars and a description for each plot. panzoom drops the lightbox options, so each plot opens in panzoom on its own, without a description.

```{r}
#| panzoom: true
#| lightbox:
#|   group: cars
#|   description:
#|     - The mtcars data, each variable against every other.
#|     - Stopping distance against speed.
#| fig-alt:
#|   - >-
#|     Scatterplot matrix of the mtcars data, each variable plotted against
#|     every other
#|   - "Scatter plot of stopping distance against speed for 50 cars"
#| fig-cap:
#|   - "The mtcars data, each variable plotted against every other."
#|   - "Stopping distance against speed for 50 cars."

plot(mtcars)
plot(cars)
```

11 Opt out a cell

An R cell with lightbox: false and no #| panzoom: true. Neither viewer takes it, so clicking it does nothing.

```{r}
#| lightbox: false
#| fig-alt: >-
#|   Scatterplot matrix of the mtcars data, each variable plotted against every
#|   other
#| fig-cap: "The mtcars data, each variable plotted against every other."

plot(mtcars)
```

12 Plain R figure

A cross-referenced R figure with no options. It isn’t marked, so clicking it does nothing.

```{r}
#| label: fig-plain
#| fig-alt: >-
#|   Heat map of the Maunga Whau volcano's heights, in yellow, orange, and red
#| fig-cap: >-
#|   Heights of Maunga Whau (Mount Eden), from pale yellow (low) to dark red
#|   (high).

```

13 Cell with a link

An R cell with #| panzoom: true and fig-link, which puts its plot inside a link. As for the image in a link, clicking the plot follows the link.

```{r}
#| panzoom: true
#| fig-link: "https://quarto.org"
#| fig-alt: "Scatter plot of vapor pressure rising steeply with temperature"
#| fig-cap: "Vapor pressure of mercury against temperature."

plot(pressure)
```
