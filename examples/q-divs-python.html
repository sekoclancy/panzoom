Python cells inside the divs built into Quarto: callouts, tabsets, and page columns, each on its own and inside a .panzoom div, as Divs (R) does for R cells and images. lightbox is off, so clicking a plot panzoom leaves alone does nothing.

A plot on a tab not selected, or in a collapsed callout, opens once the reader selects the tab or expands the callout.

Each case shows its source above the plot: Jupyter leaves panzoom: out of the echoed code of a cell.

The plots are drawn with these helpers:

```{python}
import matplotlib.pyplot as plt
import numpy as np
```
wave() 
```{python}
#| code-fold: true
#| code-summary: "wave()"

def wave(k=1):
    """Draw a sine wave with shading to zero.

    k: frequency multiplier; draws 2 * k cycles from 0 to 4 * pi.
    """
    x = np.linspace(0, 4 * np.pi, 400)
    col = plt.cm.Dark2(k - 1)
    fig, ax = plt.subplots(figsize=(7, 5))
    ax.fill_between(x, np.sin(k * x), color=col, alpha=0.35, linewidth=0)
    ax.plot(x, np.sin(k * x), color=col, linewidth=2)
    ax.set(title=f"Wave {k}", xlabel="x", ylabel="sin(kx)")
    plt.show()
```
collage() 
```{python}
#| code-fold: true
#| code-summary: "collage()"

def collage(n=12, height=0.8, width=8):
    """Draw random walks in side-by-side panels.

    n: number of panels.
    height: figure height in inches.
    width: figure width in inches.
    """
    rng = np.random.default_rng(1)
    fig, axes = plt.subplots(1, n, figsize=(width, height), layout="constrained")
    for i, ax in enumerate(axes):
        ax.plot(np.cumsum(rng.normal(size=200)), color=plt.cm.viridis(i / n))
        ax.set_title(f"Panel {i + 1}", fontsize=5)
        ax.tick_params(labelsize=4)
    plt.show()
```
