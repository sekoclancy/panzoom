lightbox comparison (Python)

panzoom is not listed under filters: in the YAML header, so every Python (Jupyter) figure opens in lightbox. The cases are the same as the ones used in panzoom on every figure, so each one can be compared with the case of the same number there. The R cases are on the lightbox comparison (R) and panzoom on every figure (R). The YAML header turns on lightbox:

---
lightbox: true
---

Jupyter leaves the panzoom and lightbox options out of the code shown on the page. The Code button at the top shows the full source.

The plots share this setup:

```{python}
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 4 * np.pi, 400)
```

1 Plot with a caption

A plot with a caption. It opens in lightbox.

```{python}
#| fig-alt: "Line plot of a sine wave"
#| fig-cap: "A sine wave."

plt.plot(x, np.sin(x))
plt.show()
```

2 Plot without a caption

A plot without a caption. It opens in lightbox.

```{python}
#| fig-alt: "Line plot of a cosine wave"

plt.plot(x, np.cos(x))
plt.show()
```

3 Subfigures

One cell with two plots, made subfigures by fig-subcap. Either one opens in lightbox, in a two-image gallery.

```{python}
#| label: fig-pair
#| layout-ncol: 2
#| fig-alt:
#|   - Line plot of a sine wave
#|   - Line plot of a cosine wave
#| fig-cap: A sine wave and a cosine wave, sin(2x) and cos(2x).
#| fig-subcap:
#|   - Sine
#|   - Cosine

plt.plot(x, np.sin(2 * x))
plt.show()
plt.plot(x, np.cos(2 * x))
plt.show()
```

4 lightbox options

One cell with two plots and lightbox: options for a group and a description. With Jupyter, lightbox ignores these options, so each plot opens in lightbox on its own, without the group or description.

```{python}
#| fig-alt:
#|   - Line plot of a sine wave
#|   - Line plot of a cosine wave
#| fig-cap:
#|   - A sine wave, sin(3x).
#|   - A cosine wave, cos(3x).

plt.plot(x, np.sin(3 * x))
plt.show()
plt.plot(x, np.cos(3 * x))
plt.show()
```

5 lightbox off

A cell with lightbox: false. Clicking the plot does nothing.

```{python}
#| fig-alt: Line plot of a sine wave
#| fig-cap: A sine wave, sin(4x).

plt.plot(x, np.sin(4 * x))
plt.show()
```

6 panzoom on a cell

A cell with #| panzoom: true. panzoom is not listed under filters: in the YAML header, so the option does nothing, and the plot opens in lightbox.

```{python}
#| fig-alt: Line plot of a cosine wave
#| fig-cap: A cosine wave, cos(4x).

plt.show()
```
