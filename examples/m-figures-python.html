This page repeats the R cell-options, caption, format, and shape cases on matplotlib figures. The YAML header sets loop, so the looping gallery wraps around.

---
filters:
  - panzoom

  hint: false
  loop: true
---

Jupyter figures are shown at their size in inches × 96 px, and written at twice that, so a figure here opens at up to twice its size on the page. Quarto gives each figure that width, so one wider than about 8 inches runs past the column. The collages here are at most 8 inches wide, where the R pages use 25.

The plots are drawn with these helpers:

```{python}
import matplotlib.pyplot as plt
import numpy as np
```
wave() 
```{python}
#| code-fold: true
#| code-summary: "wave()"

def wave(k=1):
    """Draw a sine wave with shading to zero.

    k: frequency multiplier; draws 2 * k cycles from 0 to 4 * pi.
    """
    x = np.linspace(0, 4 * np.pi, 400)
    col = plt.cm.Dark2(k - 1)
    fig, ax = plt.subplots(figsize=(7, 5))
    ax.fill_between(x, np.sin(k * x), color=col, alpha=0.35, linewidth=0)
    ax.plot(x, np.sin(k * x), color=col, linewidth=2)
    ax.set(title=f"Wave {k}", xlabel="x", ylabel="sin(kx)")
    plt.show()
```
collage() 
```{python}
#| code-fold: true
#| code-summary: "collage()"

def collage(n=12, height=0.8, width=8):
    """Draw random walks in side-by-side panels.

    n: number of panels.
    height: figure height in inches.
    width: figure width in inches.
    """
    rng = np.random.default_rng(1)
    fig, axes = plt.subplots(1, n, figsize=(width, height), layout="constrained")
    for i, ax in enumerate(axes):
        ax.plot(np.cumsum(rng.normal(size=200)), color=plt.cm.viridis(i / n))
        ax.set_title(f"Panel {i + 1}", fontsize=5)
        ax.tick_params(labelsize=4)
    plt.show()
```
strip() 
```{python}
#| code-fold: true
#| code-summary: "strip()"

def strip(seed=2, n=8):
    """Draw random walks in stacked rows.

    seed: random seed for the walks.
    n: number of rows.
    """
    rng = np.random.default_rng(seed)
    fig, axes = plt.subplots(n, 1, figsize=(3, 10), layout="constrained")
    for i, ax in enumerate(axes):
        ax.plot(np.cumsum(rng.normal(size=100)), color=plt.cm.plasma(i / n))
        ax.set_title(f"Strip {seed}, row {i + 1}", fontsize=7)
        ax.tick_params(labelsize=5)
    plt.show()
```

7 Long description

A cell with a description longer than its panel, under the panzoom cell option. It opens in panzoom, and the description panel scrolls. Tab reaches the panel, and the arrow keys, Page Up and Page Down, Home, End, and Space scroll it.

```{python}
#| fig-alt: A sine curve, shaded between the curve and y = 0
#| fig-cap: |-
#| 
#|   Wave 1: y = sin(x); the area between the curve and y = 0 is shaded.

wave(1)
```

This description is long on purpose: it is taller than the space the viewer gives a description, so its panel scrolls. With a mouse or trackpad, scrolling over the panel scrolls it. From the keyboard, Tab moves focus to the panel, and then the arrow keys, Page Up and Page Down, Home, End and Space scroll it, as they would scroll a page. The image stays where it is meanwhile, and the page behind the viewer doesn’t move. Tab again moves on to the close button, and Esc still closes the viewer. Plots like this one often come with long notes: what was measured, how, and over what range; what the axes mean; what to look for and what to ignore. Notes like these can run to several paragraphs, and a reader who uses the keyboard must be able to read all of them, not just the lines that fit. In a short window, or on a phone, the panel is smaller still, so even a description of two or three sentences can scroll there. The panel is a Tab stop only while it scrolls, so a short description adds no extra stop. The rest of this description only adds length, so that it scrolls in every window the tests use, including the wide screen, where the panel is tallest and its lines are longest. The wave rises from zero to one over the first quarter of each period, falls back to zero at the half period, reaches minus one at three quarters, and returns to zero at the end of the period. The shaded area above the axis equals the shaded area below it over each whole period, so the mean of the wave is zero. Doubling k halves the period and doubles the number of crossings, and the shading follows the curve wherever it goes. The curve is drawn with 400 points, enough that it looks smooth at any zoom the viewer allows. Its color comes from the Dark2 palette, one color per wave, and its shading is the same color at a third of the strength, so the curve stays the strongest line in the plot. The title names the wave, the x axis runs over two whole periods, and the y axis is labeled with the formula the curve follows. Each of these choices is made once, in the helper, so every wave on this page is drawn the same way and only k changes. Nothing in this description is needed for the test except its length: a description this long scrolls in any window.
