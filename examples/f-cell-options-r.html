Cell options (R)

Keeping an image or a cell out of panzoom, and setting options on one cell. The YAML header sets loop, so the looping gallery wraps around. lightbox is off, so clicking an image panzoom leaves alone does nothing.

---
filters:
  - panzoom
panzoom:
  loop: true
---

The caption and description options are on captions and descriptions, and fit is on wide and tall figures.

The plots are drawn with this helper:

```{r}
wave <- function(k = 1) {
  x <- seq(0, 4 * pi, length.out = 400)
  col <- hcl.colors(4, "Dark 3")[(k - 1) %% 4 + 1]
  plot(
    x,
    sin(k * x),
    type = "n",
    main = paste("Wave", k),
    xlab = "x",
    ylab = "sin(kx)"
  )
  polygon(
    c(x, rev(x)),
    c(sin(k * x), rep(0, length(x))),
    col = adjustcolor(col, 0.35),
    border = NA
  )
  lines(x, sin(k * x), lwd = 2, col = col)
}
```
