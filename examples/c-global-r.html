panzoom on every figure (R)

panzoom takes every image lightbox would take on its own, so no image needs to be marked. The lightbox: option in the YAML header sets up lightbox too, but only cells that ask for it with the #| lightbox: true cell option, or with lightbox options such as group, open in it. The same cases open in lightbox alone on the lightbox comparison. The YAML header sets up both, and turns off the hint line:

---
filters:
  - panzoom
panzoom:
  match: auto
  hint: false
lightbox:
  match: auto
  effect: fade
  desc-position: right
  loop: true
---

8 R subfigures

One R cell with two plots, made subfigures by fig-subcap. Either one opens in panzoom, in a two-image gallery.

```{r}
#| label: fig-r-sub
#| layout-ncol: 2
#| fig-alt:
#|   - "Scatter plot of vapor pressure rising steeply with temperature"
#|   - "Scatter plot of stopping distance against speed for 50 cars"
#| fig-cap: >-
#|   Vapor pressure of mercury, and stopping distances of cars.
#| fig-subcap: ["Pressure", "Cars"]

plot(pressure)
plot(cars)
```

9 Grouped cells

Two R cells, joined by group: r-graph under the lightbox cell option. Requesting lightbox prevents panzoom from working, so the plots open in lightbox as a two-image gallery, each with its own description on the right.

```{r}
#| lightbox:
#|   group: r-graph
#|   description: Ten random points.
#| fig-alt: "Scatter plot of ten random points"
#| fig-cap: >-
#|   Ten random points against their index.

plot(1:10, rnorm(10))
```
```{r}
#| lightbox:
#|   group: r-graph
#|   description: Stopping distance against speed.
#| fig-alt: "Scatter plot of stopping distance against speed for 50 cars"
#| fig-cap: >-
#|   Stopping distance against speed for 50 cars.

plot(cars)
```

10 Two plots in one cell

One R cell with two plots, each with its own caption and description, joined by group: cars under the lightbox cell option. Requesting lightbox prevents panzoom from working, so the plots open in lightbox as a two-image gallery.

```{r}
#| lightbox:
#|   group: cars
#|   description:
#|     - The mtcars data, each variable against every other.
#|     - Stopping distance against speed.
#| fig-alt:
#|   - >-
#|     Scatterplot matrix of the mtcars data, each variable plotted against
#|     every other
#|   - "Scatter plot of stopping distance against speed for 50 cars"
#| fig-cap:
#|   - "The mtcars data, each variable plotted against every other."
#|   - "Stopping distance against speed for 50 cars."

plot(mtcars)
plot(cars)
```

11 Opt out a cell

An R cell with lightbox: false. Neither viewer takes it, so clicking it does nothing.

```{r}
#| lightbox: false
#| fig-alt: >-
#|   Scatterplot matrix of the mtcars data, each variable plotted against every
#|   other
#| fig-cap: "The mtcars data, each variable plotted against every other."

plot(mtcars)
```

12 Plain R figure

A cross-referenced R figure with no options. It opens in panzoom, because lightbox isn’t specified.

```{r}
#| label: fig-plain
#| fig-alt: >-
#|   Heat map of the Maunga Whau volcano's heights, in yellow, orange, and red
#| fig-cap: >-
#|   Heights of Maunga Whau (Mount Eden), from pale yellow (low) to dark red
#|   (high).

image(volcano)
```

filters:
