Wide and tall figures (R)

Figures of different shapes, each opened on its own, and the fit option. All are png. Other formats are on image formats, and the same shapes in galleries and layouts are on wide figures in galleries.

With fit: auto, the default, a figure opens by its shape:

Figure Opens
Most images, photos and plots, portrait or landscape whole, never larger than its real size
Wide strip: at least 3 times wider than tall, and under a quarter of the screen tall when whole at screen height, at the spot you clicked
Tall strip: at least 3 times taller than wide, and under a quarter of the screen wide when whole at screen width, from the top

fit: contain, height, or width sets this for one figure. A small image opens at its own size, and scrolling still zooms it in, up to max-zoom.

Where you click a strip on the page is its focal point: the viewer opens with that spot in the middle of the screen. Near either end of the strip, that end lines up with the edge of the screen instead. The 0 key and double-click return to it. Opened from the keyboard, a strip starts at its left end or top. Zooming out still shows the whole figure.

Shift+scroll, or a sideways trackpad swipe, pans sideways, and Alt+scroll pans up and down.

The plots are drawn with these helpers:

```{r}
# A collage: `n` panels side by side, like a wide patchwork figure.
collage <- function(n = 12) {
  set.seed(1)
  par(mfrow = c(1, n), mar = c(3, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(
      cumsum(rnorm(200)),
      type = "l",
      main = paste("Panel", i),
      xlab = "",
      ylab = "",
      col = hcl.colors(n)[i],
      lwd = 2
    )
  }
}

# A tall strip: `n` rows stacked, like a tall patchwork figure.
# Each seed gets its own palette (without its lightest end), so different
# strips look different.
strip <- function(seed = 2, n = 8) {
  set.seed(seed)
  palette <- c(
    "Viridis",
    "Plasma",
    "Zissou 1",
    "Dark 3",
    "Sunset",
    "Cividis",
    "Dynamic",
    "Inferno"
  )[(seed - 2) %% 8 + 1]
  par(mfrow = c(n, 1), mar = c(2, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(
      cumsum(rnorm(100)),
      type = "l",
      main = paste0("Strip ", seed, ", row ", i),
      xlab = "",
      ylab = "",
      col = hcl.colors(n + 2, palette)[i],
      lwd = 2
    )
  }
}

wave <- function(k = 1) {
  x <- seq(0, 4 * pi, length.out = 400)
  col <- hcl.colors(4, "Dark 3")[k]
  plot(
    x,
    sin(k * x),
    type = "n",
    main = paste("Wave", k),
    xlab = "x",
    ylab = "sin(kx)"
  )
  polygon(
    c(x, rev(x)),
    c(sin(k * x), rep(0, length(x))),
    col = adjustcolor(col, 0.35),
    border = NA
  )
  lines(x, sin(k * x), lwd = 2, col = col)
}
```

1 Wide collage

A 25 × 2 inch collage. It opens in panzoom at screen height, and Shift+scroll moves sideways.

```{r}
#| panzoom: true
#| fig-width: 25
#| fig-height: 2
#| fig-alt: >-
#|   A row of 12 small line plots of random walks, each in its own color
#| fig-cap: "A 25 × 2 inch collage of 12 random walks."

collage(n = 12)
```
