Cell options (Python)

The cell options from the R examples, on matplotlib figures, and svg output. lightbox is not set in the YAML header, so only cells marked for panzoom open in it. Clicking any other figure does nothing, unless its cell turns lightbox on with #| lightbox: true. The YAML header turns on panzoom:

---
filters:
  - panzoom
---

Jupyter leaves the panzoom and lightbox options out of the code shown on the page, unlike knitr. The Code button at the top shows the full source.

The plots share this setup and helper:

```{python}
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(1)


def walk(ax, n=200, title=None):
    ax.plot(np.cumsum(rng.normal(size=n)))
    if title:
        ax.set_title(title)
```

1 panzoom on a cell

A cell with #| panzoom: true. It opens in panzoom, with the hint line.

```{python}
#| fig-alt: Line plot of a sine wave
#| fig-cap: A sine wave.

x = np.linspace(0, 4 * np.pi, 400)
plt.plot(x, np.sin(x))
plt.show()
```

2 Cell options

A cell with max-zoom: 2 and hint: false under the panzoom cell option. It opens in panzoom without the hint line, and zooming in stops at 2 screen pixels per image pixel.

```{python}
#| fig-alt: Line plot of a cosine wave
#| fig-cap: A cosine wave, cos(x).

plt.plot(x, np.cos(x))
plt.show()
```

3 Labeled figure

A labeled figure with math and a cross-reference in its caption, and a description with math, quotes, and a cross-reference to the subfigures. It opens in panzoom with all of them rendered.

```{python}
#| label: fig-scatter
#| fig-alt: Scatter plot of 100 points along a rising diagonal
#| fig-cap: |-
#| 
#|   100 points scattered around a rising diagonal, $n = 100$; compare @fig-sub.

pts = rng.normal(size=100)
plt.scatter(pts, pts + rng.normal(scale=0.5, size=100))
plt.show()
```

Points scattered around \(y = x + \varepsilon\), with a “quote”; compare Figure 2.

4 Subfigures

One cell with #| panzoom: true and two plots, made subfigures by fig-subcap. Either one opens in panzoom, in a two-image gallery.

```{python}
#| label: fig-sub
#| layout-ncol: 2
#| fig-alt:
#|   - Line plot of a random walk
#|   - Histogram of 500 normal draws, peaked at zero
#| fig-cap: A random walk of 200 steps, and a histogram of 500 normal draws.
#| fig-subcap:
#|   - A random walk
#|   - A histogram

fig, ax = plt.subplots()
walk(ax)
plt.show()
plt.hist(rng.normal(size=500), bins=30)
plt.show()
```

5 Plots in a group

One cell with two plots, joined by group: walks under the panzoom cell option. Either one opens in panzoom, in a two-image gallery.

```{python}
#| fig-alt:
#|   - Line plot of a random walk
#|   - Line plot of a random walk
#| fig-cap:
#|   - A random walk of 200 steps.
#|   - Another random walk of 200 steps.

for i in range(2):
    fig, ax = plt.subplots()
    walk(ax)
    plt.show()
```

6 Wide collage

An 8 × 0.8 inch collage. It is a strip, so it opens in panzoom at screen height. Jupyter figures are shown at their size in inches × 96 px (Quarto writes it on the image), not shrunk to the column as with knitr. A 25 × 2 in collage would be 2,400 px wide on the page, cut off at the edge of the column. This one fits.

```{python}
#| fig-alt: A row of 8 small line plots of random walks
#| fig-cap: An 8 × 0.8 inch collage of 8 random walks.

fig, axes = plt.subplots(1, 8, figsize=(8, 0.8), layout="constrained")
for ax in axes:
    walk(ax)
    ax.tick_params(labelsize=4)
plt.show()
```

12 svg

Jupyter saves the figure file itself, unlike knitr, and ignores fig-format on a cell, so the cell switches the matplotlib output to svg itself, and back to the default (retina png) after. svg from R is on image formats (R). The plot opens in panzoom and stays sharp when zoomed, since the viewer redraws svg at each zoom.

```{python}
#| fig-alt: Line plot of a damped sine wave
#| fig-cap: A damped sine wave, exp(-x/4) sin(3x).

%config InlineBackend.figure_formats = ["svg"]
plt.plot(x, np.exp(-x / 4) * np.sin(3 * x))
plt.show()
%config InlineBackend.figure_formats = ["retina"]
```
