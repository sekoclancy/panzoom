Dark plots (R)

Plots with dark backgrounds and plots with transparent backgrounds, in the viewer’s default 70% black backdrop. Each one is worth opening in light and dark mode (the toggle in the navbar). Renderings draws a plot for each mode instead.

The site draws R plots on white (dev.args: bg: white in _quarto.yml), so the transparent plots set bg = "transparent" in their own cells. They use the ragg_png device, since R’s own png device tints light text drawn on a transparent background.

The plots are drawn with this helper. ink colors the axes, labels, and title; paper fills the plot background, and NULL leaves the device background.

```{r}
wave <- function(k = 1, ink = "black", paper = NULL, col = "#3B7DB8") {
  if (!is.null(paper)) {
    par(bg = paper)
  }
  par(fg = ink, col.axis = ink, col.lab = ink, col.main = ink)
  x <- seq(0, 4 * pi, length.out = 400)
  plot(
    x,
    sin(k * x),
    type = "n",
    main = paste("Wave", k),
    xlab = "x",
    ylab = "sin(kx)"
  )
  polygon(
    c(x, rev(x)),
    c(sin(k * x), rep(0, length(x))),
    col = adjustcolor(col, 0.35),
    border = NA
  )
  lines(x, sin(k * x), lwd = 2, col = col)
}
```

1 Dark background

A plot on a near-black background with light gray ink. It opens on the default backdrop, which is also dark.

```{r}
#| panzoom: true
#| fig-alt: "A sine curve in light blue on a near-black background"
#| fig-cap: >-
#|   Wave 2: y = sin(2x); the area between the curve and y = 0 is shaded.

wave(k = 2, ink = "gray85", paper = "#1E1E1E", col = "#7FB8E6")
```

2 Dark background, light backdrop

The dark plot with a light gray backdrop of its own. It opens on a light gray backdrop, with the dark plot standing out against it.

```{r}
#| panzoom:
#|   backdrop: "rgba(225, 225, 225, 0.92)"
#| fig-alt: "A sine curve in light blue on a near-black background"
#| fig-cap: >-
#|   Wave 2: y = sin(2x); the area between the curve and y = 0 is shaded.

wave(k = 2, ink = "gray85", paper = "#1E1E1E", col = "#7FB8E6")
```

3 Transparent background, dark ink

A plot with a transparent background and black ink. The viewer shows it on the page background, so its axes are readable in light mode and hard to see in dark mode, on the page and in the viewer alike.

```{r}
#| panzoom: true
#| dev: ragg_png
#| dev.args: !expr list(bg = "transparent")
#| fig-alt: "A sine curve in blue with black axes on a transparent background"
#| fig-cap: >-
#|   Wave 3: y = sin(3x); the area between the curve and y = 0 is shaded.

wave(k = 3)
```

4 Transparent background, light ink

The transparent plot with light gray ink: the reverse, readable in dark mode and hard to see in light mode.

```{r}
#| panzoom: true
#| dev: ragg_png
#| dev.args: !expr list(bg = "transparent")
#| fig-alt: >-
#|   A sine curve in blue with light gray axes on a transparent background
#| fig-cap: >-
#|   Wave 3: y = sin(3x); the area between the curve and y = 0 is shaded.

wave(k = 3, ink = "gray85")
```

5 Gallery of light and dark plots

A plot on white, the dark plot, and the transparent plot with black ink, in a gallery. They open in panzoom as a three-image gallery, appearing as they do on the page prior to opening the viewer.

```{r}
#| panzoom:
#|   group: light-dark
#| dev: ragg_png
#| dev.args: !expr list(bg = "transparent")
#| fig-alt:
#|   - "A sine curve in blue with black axes on a white background"
#|   - "A sine curve in light blue on a near-black background"
#|   - "A sine curve in blue with black axes on a transparent background"
#| fig-cap:
#|   - >-
#|     Wave 1: y = sin(x); the area between the curve and y = 0 is shaded.
#|   - >-
#|     Wave 2: y = sin(2x); the area between the curve and y = 0 is shaded.
#|   - >-
#|     Wave 3: y = sin(3x); the area between the curve and y = 0 is shaded.

wave(k = 1, paper = "white")
wave(k = 2, ink = "gray85", paper = "#1E1E1E", col = "#7FB8E6")
wave(k = 3, paper = "transparent")
```
