Wide figures in galleries (R)

  • Show All Code
  • Hide All Code
  • View Source

Collages (25 × 2 inches) and tall strips in galleries, as subfigures, and in a layout div. The same shapes on their own, and the fit option, are on wide and tall figures.

Wide figures open at screen height, and tall ones at screen width. The one you click opens at the spot you clicked, and stepping to another in a gallery starts it at its left end or top. The left and right arrow keys always step through the gallery, the same as the previous and next buttons; Ctrl/Cmd+arrow pans a wide figure instead, in any direction, without changing image. The viewer keeps the sides of the screen free for the previous and next buttons, so a figure shown whole, or panned to its end, is never under one.

The plots are drawn with these helpers:

collage() 
```{r}
#| code-fold: true
#| code-summary: "collage()"

#' Draw random walks in side-by-side panels.
#'
#' @param n Number of panels.
collage <- function(n = 12) {
  set.seed(1)
  par(mfrow = c(1, n), mar = c(3, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(
      cumsum(rnorm(200)),
      type = "l",
      main = paste("Panel", i),
      xlab = "",
      ylab = "",
      col = hcl.colors(n)[i],
      lwd = 2
    )
  }
}
```
strip() 
```{r}
#| code-fold: true
#| code-summary: "strip()"

#' Draw random walks in stacked rows.
#'
#' Each seed selects a palette, omitting its lightest colors.
#'
#' @param seed Random seed and palette selector.
#' @param n Number of rows.
strip <- function(seed = 2, n = 8) {
  set.seed(seed)
  palette <- c(
    "Viridis",
    "Plasma",
    "Zissou 1",
    "Dark 3",
    "Sunset",
    "Cividis",
    "Dynamic",
    "Inferno"
  )[(seed - 2) %% 8 + 1]
  par(mfrow = c(n, 1), mar = c(2, 3, 2, 1))
  for (i in seq_len(n)) {
    plot(
      cumsum(rnorm(100)),
      type = "l",
      main = paste0("Strip ", seed, ", row ", i),
      xlab = "",
      ylab = "",
      col = hcl.colors(n + 2, palette)[i],
      lwd = 2
    )
  }
}
```

1 Gallery of two collages

Two 25 × 2 inch collages in a gallery. Each opens at screen height. The left and right arrow keys always switch between them, the same as the previous and next buttons; Ctrl/Cmd+arrow (or dragging) pans along a collage instead.

```{r}
#| panzoom:
#|   group: collages
#| fig-width: 25
#| fig-height: 2
#| fig-alt:
#|   - >-
#|     A row of 12 small line plots of random walks, each in its own color
#|   - >-
#|     A row of 15 small line plots of random walks, each in its own color
#| fig-cap:
#|   - "A 25 × 2 inch collage of 12 random walks."
#|   - "A 25 × 2 inch collage of 15 random walks."

collage(n = 12)
collage(n = 15)
```

2 Gallery of two tall strips

Two tall strips in a gallery. Each opens at screen width and extends downwards. The left and right arrow keys switch between them, the same as the previous and next buttons; there is nowhere to go sideways, so Ctrl/Cmd+Left/Right do nothing here (Ctrl/Cmd+Up/Down still pan).

```{r}
#| panzoom:
#|   group: strips
#| fig-width: 4
#| fig-height: 15
#| fig-alt:
#|   - "A column of 8 small line plots of random walks"
#|   - "A column of 8 small line plots of random walks"
#| fig-cap:
#|   - "A 4 × 15 inch strip of 8 random walks."
#|   - "A 4 × 15 inch strip of 8 more random walks."

strip(seed = 8, n = 8)
strip(seed = 9, n = 8)
```

6 Collages of different lengths

A long collage (40 × 2 in, 24 panels) and a shorter one (24 × 2 in, 12 panels) from two cells, joined by group. Each opens at screen height; moving to the other collage resets its scale and position, opening it whole from its left end rather than keeping the first collage’s zoom or pan. Only the shorter collage has a description, so the caption band changes height between them, and each collage stays clear of it. Here we use fig-dpi: 48 to keep the files small.

```{r}
#| panzoom:
#|   group: mixed-collages
#| fig-width: 40
#| fig-height: 2
#| fig-dpi: 48
#| fig-alt: >-
#|   A row of 24 small line plots of random walks, each in its own color
#| fig-cap: "A 40 × 2 inch collage of 24 random walks."

collage(n = 24)
```
```{r}
#| panzoom:
#|   group: mixed-collages
#|   description: >-
#|     Each panel is a random walk of 200 steps, colored along a single palette
#|     from the first panel to the last, and titled with its panel number so the
#|     order can be read at any zoom.
#| fig-width: 24
#| fig-height: 2
#| fig-dpi: 48
#| fig-alt: >-
#|   A row of 12 small line plots of random walks, each in its own color
#| fig-cap: "A 24 × 2 inch collage of 12 random walks."

collage(n = 12)
```

Each panel is a random walk of 200 steps, colored along a single palette from the first panel to the last, and titled with its panel number so the order can be read at any zoom.
